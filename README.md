# vectordriver-site

Sito di **Vector Driver**, servito da GitHub Pages su
<https://vectordriver.lucaporta.dev>: presentazione dell'app, informativa
privacy, termini di servizio e assistenza.

Le pagine sono **generate**: non si modificano qui. La fonte sta nel repository
dell'app (`Legale/`, `Tools/GeneraSito.py`), e `Tools/PubblicaSito.sh` copia
qui il risultato. Una modifica fatta a mano in questo repo viene sovrascritta
alla pubblicazione successiva.

Contatti: support@lucaporta.dev
